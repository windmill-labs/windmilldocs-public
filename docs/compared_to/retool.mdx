# Open source Retool alternative for internal tools

<a href="https://retool.com/" rel="nofollow">Retool</a> is a proprietary platform for building internal apps, workflows and agents on a visual canvas, wired to databases and APIs with JavaScript, SQL and, in workflows, Python.
Windmill covers the same ground as an open-source, self-hostable platform: apps, flows and scripts run on one runtime, and every piece of logic is a script you can also run on its own, on a schedule or behind a webhook.

This page is a short overview. For a section-by-section read of both products, with the plan each feature needs on either side, see the [full side-by-side comparison of Windmill and Retool](/compare/retool).

![Windmill Retool](../assets/compared_to/windmill_retool.webp 'Windmill Retool')

## Open source and self-hosting

Windmill's Community Edition is open source under AGPLv3 and can be self-hosted for free with Docker Compose or Kubernetes.
The [Windmill Hub](https://hub.windmill.dev/) is a public library of scripts, flows and apps that anyone can contribute to.

Retool is closed source and has no open-source edition.
On its <a href="https://retool.com/pricing" rel="nofollow">pricing page</a>, deploying Retool self-hosted or air-gapped is part of the Enterprise plan; Free, Team and Business run on Retool Cloud.

## Languages and logic

Retool apps use JavaScript for transformers and event handlers and SQL for queries.
Retool Workflows add <a href="https://docs.retool.com/workflows/guides/blocks/code" rel="nofollow">code blocks in JavaScript and Python</a>.

In Windmill, logic is a script in [TypeScript](../getting_started/0_scripts_quickstart/1_typescript_quickstart/index.mdx), [Python](../getting_started/0_scripts_quickstart/2_python_quickstart/index.mdx), [Go](../getting_started/0_scripts_quickstart/3_go_quickstart/index.mdx), [Bash](../getting_started/0_scripts_quickstart/4_bash_quickstart/index.mdx), [SQL](../getting_started/0_scripts_quickstart/5_sql_quickstart/index.mdx), [PHP](../getting_started/0_scripts_quickstart/8_php_quickstart/index.mdx), [Rust](../getting_started/0_scripts_quickstart/9_rust_quickstart/index.mdx), [C#](../getting_started/0_scripts_quickstart/11_csharp_quickstart/index.mdx), [Java](../getting_started/0_scripts_quickstart/13_java_quickstart/index.mdx), [Ansible](../getting_started/0_scripts_quickstart/10_ansible_quickstart/index.mdx) and [more](../getting_started/0_scripts_quickstart/index.mdx), or a [Docker container](../getting_started/0_scripts_quickstart/7_docker_quickstart/index.mdx).
Dependencies are [resolved from the imports](../advanced/6_imports/index.mdx) and pinned per script, with no package.json or requirements.txt to maintain.
Each script is also a standalone endpoint with an [auto-generated UI](../core_concepts/6_auto_generated_uis/index.mdx), a [webhook](../core_concepts/4_webhooks/index.mdx) and [schedules](../core_concepts/1_scheduling/index.mdx), so the same code serves an app, a flow and an API.

## Workflows

Retool Workflows run on a separate canvas with blocks for code, resource queries, loops and branches.
They start from <a href="https://docs.retool.com/workflows/concepts/triggers" rel="nofollow">schedules, webhooks and query triggers</a> (in beta).
Workflow runs are metered: the pricing page lists 500 runs a month on Free and 5,000 on Team, with additional runs at $75 per 5,000.

Windmill [flows](../flows/1_flow_editor.mdx) chain scripts in any of the languages above, with [approval steps](../flows/11_flow_approval.mdx), [sleep](../flows/15_sleep.md), [early stop](../flows/2_early_stop.md), [while loops](../flows/22_while_loops.mdx), retries and error handlers.
They start from schedules, webhooks, HTTP routes, or event triggers for [Kafka](../triggers/5_kafka_triggers/index.mdx), NATS, SQS, MQTT, Postgres, WebSocket and email.
Self-hosted Windmill, on Community and Enterprise Edition, has no execution limit: you size the workers that run the flows. On Windmill Cloud, the free plan includes 1,000 executions a month and the Team plan 10k per user.

## Apps

Both products have a drag-and-drop app builder connected to queries and backend code.
Windmill also lets you build [full-code apps](../full_code_apps/index.mdx) in React or Svelte, backed by the same scripts and flows.

## Developer experience and Git

Windmill can be used entirely from your own tools: the [CLI](../advanced/3_cli/index.mdx), [local development](../advanced/4_local_development/index.mdx) in VS Code or with Claude Code, and [Git sync](../advanced/11_git_sync/index.mdx), which writes every script, flow, app and trigger to a repository as files.
Git sync is free on self-hosted Community Edition for up to 2 users.

Retool apps are edited in Retool's web editor.
<a href="https://docs.retool.com/source-control" rel="nofollow">Source Control</a> syncs apps and workflows to GitHub, GitLab, Bitbucket, AWS CodeCommit or Azure Repos through pull requests, and the pricing page lists it on the Enterprise plan.

## Integrations

Retool ships a catalog of pre-built <a href="https://retool.com/integrations" rel="nofollow">integrations</a> and falls back to a generic REST or GraphQL resource for anything else.

In Windmill, any npm, PyPI, Go or Maven package is an integration, since scripts import it directly.
[Resource types](../integrations/0_integrations_on_windmill.mdx) describe connections to databases, SaaS and infrastructure, and anyone can add one.

## Pricing

Retool charges per user on <a href="https://retool.com/pricing" rel="nofollow">annual billing</a>: builders at $10 a month on Team and $50 on Business, internal users at $5 and $15, with Enterprise priced by quote.
Custom SSO, source control and self-hosting are on Enterprise.

Windmill's Community Edition is free to self-host at any scale.
Paid plans are priced on [seats and compute units](/pricing), and the [plan details](../enterprise/1_plans_details/index.mdx) list what each one includes.

## Where Retool is ahead

Retool has a large library of <a href="https://retool.com/templates/" rel="nofollow">templates</a> and a broad <a href="https://retool.com/components" rel="nofollow">component library</a>, and its canvas is approachable for people who write a little JavaScript.
If your team builds CRUD screens over a database and does not need other languages, self-hosting or Git outside Enterprise, Retool is a reasonable choice.

Windmill fits better when internal tools are one part of a wider estate of scripts, workflows, data pipelines and AI agents that you want to run on your own infrastructure, review in Git and pay for by compute rather than by run.
